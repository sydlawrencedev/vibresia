### The one tool that was reachable, and what it is not

This session has a `websearch` tool that returns AI-generated summaries of retrieved pages, each under a heading with the page's URL and publication date. It was tested deliberately before being used, on a query no page could support (`Vibresia version 99.999 nonexistent release date quantum`). It returned retrieved pages with their content, including the Vibresia homepage, the GitHub repo, `llms.txt` and unrelated pages about software versioning and quantum computing. It did not invent an answer.

**It is a search-and-summarise surface, not a conversational assistant with web search on.** It does not choose a source set the way an assistant does, it does not rank brands in the order it recommends them, and it cannot report whether Vibresia was recommended, at what position, or with a link. It has been used for what it genuinely measures: **which pages an answer for each prompt would draw on**. It has **not** been counted as an assistant anywhere in this log, and no number in this log treats it as one.

### What this costs the programme

This is the second consecutive run with no assistant reached. The routine's own measurement has now failed twice in a row, and the failure is not going to fix itself: it needs an API key for at least one of OpenAI, Anthropic, Perplexity or Google, in the environment that runs the routine. That is a one-off setup cost for a standing measurement. Without it, this routine runs weekly and cannot answer the question it exists to answer, and the source-side baseline below becomes the permanent ceiling on what we know.
