### Three measurement traps worth keeping

- **The download source property is `source`, not `src`.** Reading
  `properties.src` on `download_requested` returns NULL for all 408 events
  and the whole attribution collapses into one null row. Same for `referer`
  (one r) on the worker event against `referrer` (two r) on the browser ones.
- **`vibescape_card_viewed` fires 0 times.** The conversion model lists it
  as a funnel step. It does not exist in the data and nothing in the repo
  fires it.
- **PostHog's query endpoint returns a validation error as
  `{type, code, detail, attr}`, not as an `error` key.** A helper that checks
  `if (d.error)` treats that as a success and silently returns 0 rows. This
  is what made several queries look empty. Also: `concat('$','pageview')`
  inlines as a String into ClickHouse's `and()` and fails with
  `illegal_type_of_argument`; the literal `'$pageview'` is the reliable form.
