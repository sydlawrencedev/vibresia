# Release 0.11.06

The app changes that came out of the marketing review. The site and the
Worker went out already; this is the app half.

## What is in it

**The brand is spelled right.** The About panel said "VIBRESSIA". It now
says "VIBRESIA", like everywhere else: the HUD, the bundle name, the
installer and the website. One word, on the one screen that says who made
the thing.

**The share message credits the maker.** The pitch that lands in somebody's
chat was "Try this Vibresia vibescape — Neon Current — free, no account."
It now carries the name of the person who made it: "Try Neon Current by
Priya — a Vibresia vibescape, free." That text is the highest-frequency
string in the whole sharing loop, and if the maker's name is not in it they
get no credit in the channel where it is being shared, and the person
receiving it has no name to look for.

**A legacy share can be claimed.** A share made before capabilities
existed has no capability on record, so its maker could never list it,
change it or publish a new version of it, and the tickbox in the share
sheet was disabled with a message that told the maker somebody else could
list their own work. The site now lets the maker claim such a share when
they share it again, so the lockout is gone.

**The gallery tickbox no longer jumps.** Toggling it sends a request, and
if the site refuses, the switch went back to what it was. It now restores
the value it had before the change, rather than flipping whatever was
current, and only if you have not moved it again since. Two quick toggles
in a row no longer undo each other.

## What is not in it

The gallery on the website is now indexed and answers the questions a
visitor arrives with, and the site says what Vibresia is not as well as
what it is. None of that is in the app: it is the site and the Worker, and
both are already live.

## Before it goes out

The app has to be notarised, and the Apple credential on this machine is
not working:

```
$ xcrun notarytool history --keychain-profile vibresia-notary
Error: HTTP status code: 401. Invalid credentials.
```

The app-specific password for the Apple ID has expired or been rotated.
Make a new one at https://appleid.apple.com and store it:

```bash
xcrun notarytool store-credentials vibresia-notary \
    --apple-id "you@minithlabs.com" --team-id CQQ33F2CDJ
```

`notarytool` prompts for the password. Then:

```bash
cd VisualiserMac && ./release.sh
```

The release script refuses to publish a Developer ID build with no valid
ticket, on purpose: Gatekeeper would refuse that app for everybody, so it
aborts rather than shipping something broken.
